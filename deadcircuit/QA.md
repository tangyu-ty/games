# 断线协议验证记录

本作与《潮汐信使》独立。游戏源码在 `deadcircuit/`，离线成品为 `dist/deadcircuit.html`；原游戏入口与存档保留。

## 内容与空间

- 18 张手工地图、72 个行动阶段、144 个主目标；另有补给、证据、救援与 36 份现场文档。
- 地图在通路、门、掩体、机关与空间结构上有不同设计。医院、竞价厅和博物馆还经过额外视觉复审，修正四角房间结构过于相似的问题。
- 14 款武器、28 个可拆配件、6 个槽位。16 类敌人覆盖安保、感染者和机械，安保与机械同盟，双方与感染者敌对。
- 18 章、18 个抉择、18 封信、3 个结局；514 条独立对白（含 72 条阶段通讯），正文与现场文档合计 39,260 个中文叙事汉字。此数字不含简报、标题和 UI 标签。
- 2–3 小时是正常首次体验的设计目标，包含探索、战斗、整备和自主阅读。熟练路线、跳读或直奔主线会缩短时间，不能用目录里的预计分钟数证明实测时长。

## 验证方法

地图测试检查独立拓扑、全部主可选目标和出口可达、门锁阶段链、按敌人真实半径避障、动态门与掩体碰撞、机关引用及不同实例状态隔离。

军械测试检查兼容性、原子装拆、替换退件、缩容退弹、拒绝事务不改变库存、解锁幂等和恶意存档白名单。AI 测试检查视线、旧声源搜索、真实换弹窗口、可闪避的狙击与冲锋、医疗不复活、有限且可中断的呼援、阵营交火。

浏览器功能和战斗测试使用真实 DOM、键盘、鼠标、标准 Gamepad API 与 CDP 触摸。真实 rAF 验证了子弹命中、门墙挡弹、翻越落脚、投掷爆炸、双向烟雾视线、闪光中断和点射节奏。小型受控战斗场景是测试夹具，不计作自然游玩时长。

战役分支测试通过明确标记的状态夹具覆盖三条完整 18 关路线、72 阶段与 144 主目标、逐行对白、18 次抉择、三个结局、重载、重试、护送和现场文档。直接定位、清敌、交互及送 NPC 到出口只验证条件与状态，不能声称完成一次自然战役。

自然流程工具 `deadcircuit/scripts/playtest.mjs` 只读游戏状态进行路线和瞄准规划，通过普通手柄轴、按键与可见 UI 操作。没有改写生命、伤害、任务、位置和时钟，也不调用手动更新方法。对白停留明确称为模拟阅读，不冒充真人阅读。工具记录活动游玩、阅读、死亡、重试、逐阶段覆盖、错误和产品源哈希；源文件变化会令冻结版本验证失败。

## 自审中修正的问题

- 触屏初始化使用了未定义的 canvas 局部变量。
- Enter / Space 的浏览器默认按钮点击与游戏输入重复推进对白。
- 默认焦点落在“收起本段”，已改为优先“继续”。
- AI 的目标引用形成循环，已改为纯数据敌人快照。
- 恶意快照绕过军械弹药归一化或使用非法武器索引。
- 三连发中途打开军械库换枪后，残余发数会射出新武器。
- 字符串配件奖励没有兑现，以及重试可重复领取物件奖励。
- 烟雾圆内起点的视线交点计算不正确。
- 断电后的炮塔仍被算作任务威胁。
- 翻越落脚点无效会卡进掩体，现先验证完整落脚空间。
- 近距离目标与撤离点缺少视线条件，可隔墙互动，现要求几何视线并先操作关闭的门。
- 护送与死亡重载、友方碰撞半径、最低保障资源的一致性。
- 320px 下简报档案入口被隐藏，已恢复。
- 手柄缺少长文档滚动与原生下拉框选择，已补右摇杆滚动及 A 切换。
- 真实护送中的圆形角色转角被近似碰撞误判无路，已改精确圆扫掠并实际逐步走通复现点。
- 敌方无线电与医疗次数在读档时重置，已持久保存次数和任务援兵预算。
- 濒死或零生命的已救 NPC 检查点可能立即再次失败，重试提供 70% 生命保障；移除了重复且无视墙体的额外近身伤害。

## 实测边界

真实 UI 已检查 1440×900、390×844、320×568、844×390，菜单、对白、简报、军械和手册无页面异常或横向溢出。18 张实际地图已生成俯瞰图并逐张目视复查。

实测浏览器为 Chromium。手柄使用标准 API 自动输入，未连接实体手柄，不声称所有型号或 Safari / Firefox 已通过。离线成品通过 HTTP 单资源加载、实际开始任务和移动验证；受管浏览器对 file:// 的限制不算离线文件已被实体浏览器全面实测。

最后的功能对照还验证了实际最终指挥官可由主线或可选证据迫使停火、方向装甲的正侧面伤害差异、塔台节点撤销平台装甲，以及搬运车接管证据箱后解除负重。全部 16 类敌人都出现在真实关卡的初始或响应遭遇中。

微光配件使用真实军械装拆后进行 Chromium 像素及视线采样：暗区固定区域亮度由 33.12 提到 49.22，拆卸恢复；820px 且视线通的目标随装备显隐。生物探头仅给 250px 内感染者粗方向提示，墙后实体仍不可见。

最终完整回归与自然流程结果在完成后写入本文件及公开验证摘要。
