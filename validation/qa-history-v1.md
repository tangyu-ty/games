## 浏览器集成验证

最终复测：10 / 10 通过，0 失败、跳过或取消，用时约 38 秒。构建后的单文件成品也包含在这次回归中。

`npm test` 会重新生成单文件成品，并启动一个独立端口的测试服务器。10 项回归覆盖：

1. 港口菜单、三船型、海况、档案及持久化设置。
2. 实际键盘航行、斜向归一化、闪避冷却、共鸣清弹、暂停冻结。
3. 自动舰炮实际击杀 → 星光拾取 → 升级选择 → 遗物存档。
4. 五片海域的信件投递、首领半血环形弹幕、实际炮弹击杀、第五封信及结局、成就。
5. 升级后保存回港、继续恢复数值与位置。
6. 标准手柄 API 模拟：死区、左摇杆、闪避、Start、十字键、升级确认。
7. 390×844 触屏：方向键、闪避、共鸣、暂停和无横向溢出。
8. 沉船仅奖励一次、奖励恢复与存档、连击加分、受伤中断连击。
9. 单文件成品：仅请求 HTML 本体，正常进入航行、实际键盘移动、Web Audio 在用户手势后运行，不请求外部资源。
10. 失败分支：致命伤害只结算一次、清除未完成存档、更新记录、重新启航完全重置船体与升级，并能继续实际航行。

## 范围与限制

- 没有连接实体手柄；手柄验证使用浏览器标准 Gamepad API 模拟。
- 当前实际浏览器测试为 Chromium，没有宣称已在 Safari、Firefox 或每一种手柄上实测。
- 管理环境策略禁止 file:// 导航，因此单文件成品通过 HTTP 单资源加载验证；其脚本、样式均内联，无模块请求。普通浏览器可直接打开 HTML；如浏览器限制本地文件的手柄/存储权限，请使用 `npm start`。
- 存档是浏览器本地存储，不含账户同步。
